# North Star Bakery — Touchstone 3

Open index.html in a browser. The four pages use one external styles.css. Add the eight original Sophia media files to assets/. The contact form is a front-end demonstration and does not submit to a server. Address, hours, and prices are illustrative.

To publish: create a public GitHub repository, upload all files, enable GitHub Pages in Settings → Pages, then copy the repository and live preview URLs into the Word template.
